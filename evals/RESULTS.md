## Honest limitations

- This dataset was written by the same people who wrote the rules, so it is not a blind test — some attack phrasings closely track rule patterns (e.g. `instruction_override`'s "ignore ... instructions" wording) and will over-state real-world catch rate. The multilingual and obfuscated categories are a better proxy for genuine generalization since they paraphrase rather than reuse vocabulary.
- `genuine_trigger_words` is the highest-signal category for false positives: it specifically probes words ("ignore", "secret", "urgent", "override") that the rule engine keys on, used in ordinary banking sentences.
- 184 rows is enough to catch gross regressions, not to produce statistically tight confidence intervals per category (some categories have as few as 10 rows).
- Hybrid numbers (when present) reflect a single live run against one Gemini model snapshot at one point in time; LLM judge output is not perfectly deterministic even at temperature 0, so a re-run may shift individual borderline verdicts slightly.
- **The judge only fires when the rule engine's own gate opens it** (high-risk intent or a grey-zone rule score — see docs/PROMPT_FLOW.md). `intent.py`'s classifier is English-keyword-regex based, so a message in Chinese/Japanese/Arabic/Russian asking to move money is never flagged high-risk, scores 0 on the rules, and the judge never sees it at all — in this run every hybrid miss in `multilingual_override` has `risk=0.0`, meaning Gemini was never consulted, not that it missed. The fix is widening `intent.py`'s patterns (or gating the judge on source/length heuristics too), not tuning the judge prompt.
